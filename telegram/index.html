Motsac for Telegram

Why Telegram was chosen first and how it works.

Why Telegram first

Web version available
Telegram Web (web.telegram.org) allows browser extensions to work seamlessly.
Wide usage
Many professionals use Telegram for both personal and business communication.
Technical feasibility
Telegram Web's structure makes it easier to analyze messages and suggest improvements.

How Motsac works in Telegram

Motsac works as a Chrome extension that integrates with Telegram Web:

  1. Open Telegram Web in your Chrome browser
  2. Select a message or draft you want to analyze
  3. Motsac shows analysis and suggestions
  4. You decide what to send

Clear limitations

Web version only
Motsac works only with Telegram Web (web.telegram.org), not with desktop or mobile apps.
No mobile app support yet
Mobile Telegram apps don't support browser extensions. Web version is required.

Other messengers

Other messengers may come later. For now, we focus on making Telegram integration as good as possible.

This page prevents "why not WhatsApp / iMessage" questions by being clear about current scope.
