Install Motsac

Install the Chrome extension to use Motsac with Telegram Web.

Install from Chrome Web Store
Now available for Telegram Web (version A)

How to use

  1. Install the extension from Chrome Web Store
  2. Open Telegram Web (web.telegram.org)
  3. Select a message to analyze

Important notes

Telegram Web only
Motsac currently works only with Telegram Web version.
No automatic sending
You decide what to send. Motsac only suggests approaches.
