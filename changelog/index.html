Changelog

Product updates and changes.

2026-04-07 — v0.4.0

Added

  • Message Editor after parsing
  • Ability to remove individual words from messages
  • Ability to remove entire messages
  • Support for editing before seeing the final result

Improved

  • Result JSON consistency after message deletion
  • Handling of media messages after removal

Notes

  • Editing is optional and fully local

Data Control

  • Users can modify or remove message content before it is processed
  • Processing now occurs only after optional user review and editing
  • No additional data collection introduced in this version

2026-03-29 — v0.3.0

  • Improved stability of Telegram message parsing
  • Richer message and chat context in parser output
  • Improved visible chat detection and results

2026-03-20 — v0.2.0

  • Added user consent system (Terms & Privacy agreement required before usage)
  • Implemented Telegram-based authentication via @motsac_bot
  • Introduced persistent user identity layer
  • Added consent logging
  • Restricted extension functionality until user consent and authentication
  • Security: one-time auth codes with expiration (TTL)

Data Protection

  • Explicit user consent required before any functionality is enabled
  • Extension functionality is blocked until consent is provided

2026-02-24

  • Added legal foundation: Terms of Use v1.1 and Privacy Policy v1.1
  • Implemented extension consent architecture
  • Clarified AI usage disclaimer and limitation of liability
  • Prepared identity binding flow for v0.2
  • Confirmed no background monitoring of Telegram activity
